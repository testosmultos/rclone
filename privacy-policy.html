Privacy Policy

Last Updated: 19/10/2026

1. Introduction

This Privacy Policy describes how this application (“the Application”) handles user data when interacting with Google OAuth 2.0 services. The Application is a personal or experimental project and is not intended for commercial use. The Application does not sell, share, or transfer user data to third parties.

2. Information We Collect

The Application may request access to certain Google account information through Google OAuth 2.0. The specific data requested depends on the scopes selected during authorization.

Typical data may include:

  • Basic profile information (e.g., name, email address)
  • Access tokens required to interact with Google APIs
  • Metadata associated with Google Drive files (if Drive API is used)

The Application does not collect any additional information beyond what is provided by Google during the OAuth authorization process.

3. How Information Is Used

User data obtained through OAuth is used solely for the purpose of enabling the Application to interact with Google services on behalf of the user.

Examples include:

  • Accessing Google Drive files
  • Listing or modifying user data stored in Google services
  • Performing operations explicitly requested by the user

The Application does not use the data for analytics, advertising, or profiling.

4. Data Storage

The Application may store OAuth tokens locally on the user’s device to maintain authentication. No user data is stored on external servers, cloud services, or third‑party systems.

Users may delete all locally stored data at any time by removing the Application’s configuration files.

5. Data Sharing

The Application does not share, sell, or disclose user data to any third parties. Data is only transmitted to Google APIs as required to perform user‑initiated actions.

6. Security

The Application uses industry‑standard OAuth 2.0 mechanisms provided by Google. Users are responsible for securing their own devices and environments where OAuth tokens may be stored.

7. Children’s Privacy

This Application is not intended for use by children under the age of 13. No data is knowingly collected from children.

8. Changes to This Policy

This Privacy Policy may be updated periodically. The “Last Updated” date at the top of this document reflects the most recent revision.

9. Contact

If you have any questions about this Privacy Policy, please contact the project owner via the GitHub repository where this Application is hosted.
