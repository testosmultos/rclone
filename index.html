rclone – Application Information

This website provides information about the rclone application used for personal and experimental purposes. This application integrates with Google OAuth 2.0 to allow users to access their Google Drive files through rclone.

Purpose of the Application

The application enables users to authenticate with Google and interact with their Google Drive data using rclone. It is not a commercial product and is used solely for personal or experimental workflows involving file synchronization and remote storage access.

Why Google OAuth Is Required

The application uses Google OAuth 2.0 to:

  • Authenticate the user securely
  • Access Google Drive files on behalf of the user
  • Perform file operations explicitly requested by the user

Scopes Used

The application may request the following Google OAuth scopes:

  • https://www.googleapis.com/auth/drive – Full access to Google Drive
  • https://www.googleapis.com/auth/drive.file – Access to files created or opened by the app
